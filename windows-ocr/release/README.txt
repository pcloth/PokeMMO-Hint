PokeMMO 属性提示 — Windows x64

使用方法
1. 把整个 ZIP 解压到普通文件夹。不要只复制 EXE，不要直接在压缩包中运行。
2. 双击 Start.cmd。首次缺少 Tesseract 时会通过 winget 安装 OCR 引擎，可能出现系统安装确认。
   本包已带简体中文模型，不需要 Rust、编译器或 ROM，也不修改游戏文件。
3. 打开窗口或无边框模式的 PokeMMO，禁用以前测试过的名字修改 Mod。
4. 悬停图标查看按钮说明。最左播放按钮开始／暂停；加号添加选区。
5. 每个选区只框一只敌人的中文名字或 No.编号。多个布局、多个敌人分别添加选区。
6. 选区名称可直接编辑，点击软盘保存；左侧四向箭头按钮查看／调整当前选区。
   拖动框内移动，拖动边缘或角缩放；Enter 保存，Esc 取消。
7. 识别结果显示首个弱点；悬停展开完整属性卡片。窗口最小化后仍可继续识别。

数据范围
覆盖全国编号 1–649 的基础形态，使用第五世代属性规则。
不判断特性、道具、变化形态或战斗中的属性变化，不自动操作游戏或推荐实时队伍。
只识别中文物种名或 No./# 编号；昵称无法可靠匹配。小字号识别率受游戏 UI 大小影响。

首次安装失败
安装 Windows“应用安装程序”以启用 winget，或者从以下页面手动安装 Tesseract：
https://github.com/UB-Mannheim/tesseract/wiki
然后重新双击 Start.cmd。也可设置 POKEMMO_TESSERACT 环境变量指定 tesseract.exe。
已安装引擎后，识别在本地离线运行；首次安装引擎需要网络。

配置与升级
选区、名称和窗口位置保存在 %LOCALAPPDATA%\PokeMMOHint\regions.txt。
升级时退出旧程序，解压新版本到新目录，配置会自动沿用。
需要重置时，退出程序后删除上述配置文件。

隐私与反馈
截图、识别和查询在本机完成，不上传到云端。程序不会读取游戏进程内存或自动点击。
反馈问题时说明版本、Windows 版本、游戏 UI 缩放和按钮状态，附裁剪后的问题画面。
第三方说明见 THIRD_PARTY_NOTICES.txt；文件校验值见 SHA256SUMS.txt。
