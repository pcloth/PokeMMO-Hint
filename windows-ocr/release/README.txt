PokeMMO 属性提示 — Windows x64

使用方法
1. 把整个 ZIP 解压到普通文件夹。不要只复制 EXE，不要直接在压缩包中运行。
2. 双击 pokemmo-hint.exe。本包已带 Tesseract 引擎、运行 DLL 和简体中文模型。
   不需要联网安装、管理员权限、Rust、编译器或 ROM，也不修改游戏文件。
3. 打开任意宝可梦游戏、模拟器或图鉴页面，让中文名字／编号清晰可见；无需检测 PokeMMO 进程。
4. 悬停图标查看按钮说明。最左播放按钮开始／暂停；加号添加选区。
5. 每个选区只框一只敌人的中文名字或 No.编号。多个布局、多个敌人分别添加选区。
6. 选区名称可直接编辑，点击软盘保存；左侧四向箭头按钮查看／调整当前选区。
   拖动框内移动，拖动边缘或角缩放；Enter 保存，Esc 取消。
7. 识别结果显示首个弱点；悬停展开完整属性卡片。窗口最小化后仍可继续识别。

数据范围
覆盖全国编号 1–649 的基础形态，使用第五世代属性规则。
不判断特性、道具、变化形态或战斗中的属性变化，不自动操作游戏或推荐实时队伍。
只识别中文物种名或 No./# 编号；昵称无法可靠匹配。小字号识别率受游戏 UI 大小影响。

引擎无法启动
请保留 ocr 文件夹内的全部 DLL，重新完整解压发布包，确认系统为 Windows x64。
无需把 Tesseract 安装到系统，也无需配置环境变量。
只要游戏画面可见，OCR 可离线使用。中文模型与内置引擎一起运行，不使用本机其他版本。

配置与升级
发行程序为 GUI 应用，正常启动只显示主界面；不要使用旧版本的 Start.cmd。
选区、名称和窗口位置保存在 %LOCALAPPDATA%\PokeMMOHint\screen-regions.txt。
选区固定在屏幕位置；移动／缩放目标窗口后，用调整按钮重新定位。
显示器布局或屏幕分辨率改变后，需要重新框选。
从旧版窗口坐标升级时需重新框选一次，旧 regions.txt／roi.txt 文件保留；此后屏幕选区会自动沿用。
需要重置时，退出程序后删除上述配置文件。

隐私与反馈
截图、识别和查询在本机完成，不上传到云端。程序不会枚举、打开或查询游戏进程，也不会自动点击。切换应用后仍识别固定屏幕选区，需要停止时点击暂停。
反馈问题时说明版本、Windows 版本、游戏 UI 缩放和按钮状态，附裁剪后的问题画面。
第三方说明见 THIRD_PARTY_NOTICES.txt；文件校验值见 SHA256SUMS.txt。
