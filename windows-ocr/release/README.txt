PokeMMO 属性提示 0.7 — Windows x64

解压 ZIP，双击 pokemmo-hint.exe，无需 Rust、ROM 或编译器。
本版不再附带 Tesseract，也不随包分发模型或额外推理引擎。

识别设置
点击工具栏齿轮，选择 Windows 中文 OCR 或 PP-OCRv6 tiny。
Windows OCR 使用系统简体中文识别功能。未安装时，点击语言设置按钮，
在简体中文语言选项中安装“光学字符识别”，然后回到程序点击重试。
系统安装可能要求管理员权限，也可直接改用 PP-OCR。
PP-OCR 首次选择后自动下载约 4.46 MB 模型和约 17 MB 推理组件；
模型默认走 hf-mirror.com，可切换官方源。组件来自 Microsoft 官方 NuGet。
下载完成并加载检查通过后，点击对勾应用。失败可重试，取消保留已完成缓存。
设置中可选择识别刷新率：每秒 0.5／1／2／4 次，默认目标每秒 1 次；
实际速度受识别耗时和选区数量影响。修改刷新率不重新下载模型。
设置和缓存保存在 %LOCALAPPDATA%\PokeMMOHint，之后可离线使用。
若 PP-OCR 组件加载提示缺少 VC++ x64 运行库，需要安装微软官方运行库，
也可以使用 Windows OCR。模型体积不是完整引擎体积，缓存解压占用另计。

使用
按钮均可悬停查看说明。最左播放按钮开始／暂停，加号添加选区。
每个选区只框一只敌人的名字或 No.编号，可分别添加群怪、单人或图鉴布局。
名称可直接修改，点击软盘保存；四向箭头可拖动调整选区，Enter 保存／Esc 取消。
点击开始，启动成功后主窗口自动最小化，失败则留在窗口显示错误。
识别成功后各选区上方显示首个弱点，悬停展开完整卡片，包含弱点、普通伤害（1倍）、抗性和免疫。
成功后仍持续识别。
可使用标题栏最小化，选区和引擎选择自动保存。移动游戏窗口后需调整选区。
截图只在本地识别，不上传，不检测游戏进程，也不自动操作游戏。

数据与识别范围
基础全国编号 1–649，第二至第五世代属性表，无妖精属性。
不判断特性、道具、变化形态或战斗中改变的属性，不提供实时队伍推荐。
白字提取、灰度和二值化可改善输入，但不保证小字号识别率。
PP-OCR 字表仍缺少“貘、狃、鲶、聒”，涉及 6 个物种；可确认候选或框选 No.编号。
昵称和英文名字暂不支持。无可靠识别时清除旧标签。

升级与反馈
建议解压到新文件夹，不需要旧版 ocr 目录或 Start.cmd。
选区文件：%LOCALAPPDATA%\PokeMMOHint\screen-regions.txt
引擎偏好：%LOCALAPPDATA%\PokeMMOHint\ocr-settings.txt
旧 regions.txt／roi.txt 不覆盖，仍需重新框选旧版相对窗口坐标。
反馈请附版本、所选引擎、Windows 版本、界面缩放、识别状态与裁剪截图。
第三方说明见 THIRD_PARTY_NOTICES.txt，发行文件校验见 SHA256SUMS.txt。
